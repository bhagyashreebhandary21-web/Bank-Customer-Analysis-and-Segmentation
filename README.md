# Bank Customer Analysis and Segmentation

## Project Overview

This project analyzes bank customer transaction data to understand customer behavior, transaction patterns, and customer segments.

The analysis was performed using Python and focuses on data cleaning, exploratory data analysis (EDA), visualization, and customer segmentation.

## Objectives

- Analyze customer transaction patterns
- Study transaction amounts by age and gender
- Analyze customer locations
- Examine account balance patterns
- Segment customers based on transaction frequency
- Identify useful insights from the data

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Customer Segmentation

Customers were divided into three groups based on their number of transactions:

- **One-Time Customer:** 1 transaction
- **Occasional Customer:** 2–5 transactions
- **Frequent Customer:** More than 5 transactions

## Key Findings

- The average transaction amount was approximately ₹1,574.
- Customers aged 41–50 had the highest average transaction amount.
- Female customers had a slightly higher average transaction amount than male customers.
- Mumbai had the highest number of transaction records among the top locations.
- Frequent customers had the highest average transaction amount.

## Dataset

The project uses a large bank transaction dataset containing more than one million transaction records.

A smaller sample dataset is included in this repository for demonstration purposes.
